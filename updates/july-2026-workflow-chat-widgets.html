Bring workflow-powered chat to your website

Embeddable workflow chat, self-service widget management, and simpler agent setup make it easier to put Mach 1 to work.

July 25–31, 2026 · 4 improvements

Why it matters

Let administrators manage website chat and troubleshoot connections without waiting for an engineering deployment.

In this release

01Embeddable workflow chat02Self-service widget management03Drag-and-drop image uploads04On-demand connection checks
Explore Mach 1 →

Improvement 01

Embeddable workflow chat

Add a public chat experience powered by Mach 1 workflows to your website.

What this means for your team

Make your workflows available through a chat experience where visitors already are.

Improvement 02

Self-service widget management

Administrators can create, edit, enable, disable, and install public widgets from the Chat Widgets settings page, with protected security credentials.

What this means for your team

Manage website chat from one settings page without an engineering deployment for each change.

Improvement 03

Drag-and-drop image uploads

Drag multiple images directly into the agent setup interface.

What this means for your team

Add images during setup with fewer individual upload steps.

Improvement 04

On-demand connection checks

Test external tool connections and see active connections or detailed feedback when a check fails.

What this means for your team

Identify connection problems while setting up an integration.

Behind the experience

  • Agent execution gained development and production environment controls.
  • Legacy API route cleanup and routine agent production updates support maintainability and reliability.
